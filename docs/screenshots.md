# Screenshots and Demo Notes

Place lightweight portfolio media here when preparing the project for GitHub or a case-study page.

Recommended captures:

- `desktop-hero.png`: first viewport with the KineticSip hero.
- `desktop-scroll-story.mp4` or `.webm`: short screen recording of the pinned GSAP product story.
- `mobile-story.png`: mobile layout showing the simplified product motion section.
- `final-cta.png`: final call-to-action and tasting profile section.

Keep large raw recordings out of the repository. Compress demos before uploading, or host larger files externally and link to them from the portfolio write-up.
